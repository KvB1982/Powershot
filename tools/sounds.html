🔊 Geräusche anhören

Hier kannst du jedes Geräusch von Powershot Tennis einzeln anhören. Gefällt dir eins nicht? Merk dir den Dateinamen – dann kann man es austauschen oder in js/audio.js (Tabelle KLAENGE) leiser stellen. Woher alles kommt: sounds/QUELLEN.md.

So klingt es im Spiel

Diese Knöpfe benutzen denselben Code wie das Spiel: Jedes Mal kommt eine andere Aufnahme, harte Schläge sind lauter, jeder Belag klingt anders.
